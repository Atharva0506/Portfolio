# Contributing Guidelines

Thank you for your interest in contributing to our portfolio project! We welcome all contributions, from bug reports and feature requests to code contributions and documentation updates.

## How to Contribute

1. **Fork the repository** to your own GitHub account.
2. **Clone the project** to your local machine.
3. **Create a branch** for your feature or bug fix (`git checkout -b feature/your-feature-name`).
4. **Make your changes** following our coding standards.
5. **Commit your changes** (`git commit -m 'feat: add some feature'`). We use conventional commits.
6. **Push to the branch** (`git push origin feature/your-feature-name`).
7. **Open a Pull Request** against the main branch.

## Setting Up Locally

- Make sure you have Node.js and pnpm installed.
- Run `pnpm install` to install dependencies.
- Run `pnpm run dev` to start the development server.

## Code Style

- We use Prettier for code formatting and ESLint for linting.
- Make sure your code passes all lint checks before opening a PR.

Thanks again for helping make this project better!
